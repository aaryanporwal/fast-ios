Built for agents.

Each agent gets its own light simulator, a screenshot with the screen's layout, and services turned back on when the app needs them.

--jsonMCP serverAgent Skillllms.txt
fast-ios run --app MyApp.app               # opens your app on a light simulator
fast-ios shot --app MyApp.app --udid <ID>  # saves a screenshot and what is on screen
fast-ios release <ID>                      # gives the simulator back

run prints the simulator's ID; pass it to shot and release.

Install.

Terminal Recommended

curl -fsSL https://raw.githubusercontent.com/aaryanporwal/fast-ios/main/packaging/install.sh | bash

Installs the menu-bar app and the command, then opens the app. No password, no security warning. Read the script.

Homebrew

brew install aaryanporwal/fast-ios/fast-ios

Builds from source on your Mac.

Mac app

Download the DMG

The app is free and not notarized with Apple, so the first time macOS says “fast-ios” Not Opened. Click Done (not Move to Trash), then Open Anyway in System Settings, Privacy & Security.

macOS 15 or newer, Xcode, and an iOS 18.5 or newer simulator.
